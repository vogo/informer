# 桌面应用自动更新方案

## 更新范围

采用完整桌面应用更新。Vue 页面嵌入 Go 可执行文件，业务核心与界面绑定共同编译，拆开更新容易产生接口不兼容，因此不单独热更新核心或前端。

| 平台 | 后台下载 | 替换对象 |
| --- | --- | --- |
| macOS Intel / Apple Silicon | `informer-ui-vX.Y.Z-darwin-universal.app.zip` | 当前整个 `informer.app` 包 |
| Windows amd64 | `informer-ui-vX.Y.Z-windows-amd64.zip` | 当前 `informer-ui.exe` |
| Linux amd64 | `informer-ui-vX.Y.Z-linux-amd64.tar.gz` | 当前 `informer-ui` |

更新不卸载应用，不执行 DMG/NSIS/DEB，不更新独立 CLI。配置、密钥、数据库和日报继续使用 `~/.informer`（或 `INFORMER_HOME`），不随应用替换。

## 用户流程

1. 正式版本每次启动立即在后台查询 `vogo/informer` 的 GitHub 最新正式 Release，应用持续运行时每 24 小时再检查。应用关闭时不运行驻留服务，下次启动补查。开发版本和 CI 构建不检查。
2. 只接受比当前版本更新的正式版本；草稿、预发布和不匹配当前平台的包不安装。
3. 自动下载到临时目录，显示下载进度。必须取得该包的 SHA256 校验值，完成校验并解压后才进入“可重启”状态。失败保留当前应用，下次启动或下一检查周期重试。
4. 顶部当前版本号旁显示圆形向下箭头，悬浮提示“新版本已下载，点击重启更新”。下载、校验期间不能点击更新。已准备好的包保持待更新状态，不因每日检查重复下载或被清除。
5. 用户点击一次按钮后，按钮进入忙碌状态。先检查安装目录可写，再交给 Wails helper；helper 等待旧进程退出、备份当前应用、替换、重新启动，成功后清理备份。helper 模式必须在配置、数据库和业务初始化之前处理。
6. 新进程的版本号来自发布 tag，显示新版本。重启调用失败时保留可点击按钮并显示错误，可重试。

前端先订阅事件，再读取后台当前状态，并定期同步，避免启动检查在页面加载之前完成而漏掉通知。

## 实现与发布约定

复用仓库锁定的 Wails `v3.0.0-beta.8` updater 与 GitHub provider，下载、解压、校验和进程替换由其实现。应用负责检查调度、强制 SHA256、状态同步和按钮。检查循环由应用生命周期取消，同一时间只有一个检查下载流程。

现有 release.yml 已构建上述三种更新包与 `SHA256SUMS`，通过 tag 注入版本号，所有平台构建成功后汇总发布。tag 使用 `vX.Y.Z`，完整发布资产上传后才向用户提供正式 Release。源码 zip、CLI 包与手工安装包不能被自动更新器选中。

SHA256 用于传输完整性验证，信任边界仍为 GitHub 仓库和 HTTPS；本期不引入独立签名密钥。未来发布签名、公证需要同步纳入构建流程。

## 平台边界与失败恢复

- 一键更新要求安装位置可由当前用户写入。macOS 请先把应用从 DMG 放入可写的应用目录；Windows 的受保护安装目录、Linux 由 root 安装的 `/usr/bin` 需要手工安装或管理员部署，本期不自动提权。预检查失败时应用保持运行并说明原因。
- 当前 macOS 发布包未签名、公证，系统安全策略仍可能阻止首次启动或新版本启动，不能承诺绕过 Gatekeeper。
- Wails beta.8 helper 会在替换失败或进程启动调用报错时尝试恢复备份；这不是新版本健康检测，应用启动后崩溃不会自动回滚。数据库迁移也不在二进制回滚范围内。
- Wails beta.8 以临时目录暂存并通过 rename 替换，暂存目录与安装目录需在同一文件系统；跨卷安装应手工更新。本期不改写底层 helper，也不承诺断电时原子替换。
- 下载状态只在本次进程内保留，关闭后再次启动会重新检查、下载；不提供断点续传。helper 日志位于系统临时目录 `wails-update-<PID>.log`。

## 验证与验收

自动化验证覆盖平台选包、版本比较、缺失/错误校验值拒绝、下载与校验状态、准备完成后不重复下载、取消检查循环。前端执行类型检查与生产构建。

发布验收必须在三个平台分别使用两个真实版本：安装旧版本 → 发布新版本 → 启动检查或等待周期 → 后台下载 → 圆形箭头 → 单击 → 自动退出并重新打开 → 版本号变更，确认订阅、密钥和历史数据保持。另验证断网、只读安装目录、损坏包与 helper 回滚。自动化测试通过不代表这些真机验收已经完成。

参考：[Wails 更新流程](https://wails.io/guides/updater/)、[GitHub Releases API](https://docs.github.com/en/rest/releases/releases)。实现行为以本仓库锁定的 beta.8 源码为准。
